When configuring an Anthropic-compatible integration, use the endpoint and environment-variable format specified by AgentRouter's current documentation rather than assuming that every OpenAI-compatible setting applies unchanged.

API Keys

Keep API keys private.

Do not:

Commit API keys to GitHub
Put API keys in public source code
Share API keys in screenshots
Paste API keys into public issues
Store production keys in client-side code

If a key is accidentally exposed, rotate or revoke it through the appropriate account controls.
